# NodeStorm

[English](README.md) · **中文**

NodeStorm 是一个用来头脑风暴和学习概念的图谱工具，每个概念都是画布上的一张卡片。你按名称添加概念，NodeStorm
会去百科、维基和网页搜索结果里为它找定义，**用的是来源自己的原话**。AI 会给这些来源打分，但你最终保留的定义不是 AI
写的。让 AI 检查时，它会找出每个概念的前置知识（缺少的前置知识会阻塞这个概念，直到你把它安装进来），分别从两个方向
说明两个概念之间的关系，提出新的概念，讲解概念并出题考你。它还能陪你一步步推导一道题，但只给提示。

它完全在浏览器里运行，使用你自己的 API 密钥；没有密钥也可以用不需要密钥的离线演示。你的图谱只保存在你的浏览器里。
如果愿意，也可以让本地服务器来保管密钥。

- **在线试用：** <https://kmaj1st.github.io/nodestorm/>。在设置里选 **离线演示**，不用密钥就能体验。
- **开发者与维护者：** 见英文 README 的 [Developer guide](README.md#developer-guide)、
  [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)（技术说明）和 [CHANGELOG.md](CHANGELOG.md)（最近的改动）。

## 快速上手

1. 打开[在线版](https://kmaj1st.github.io/nodestorm/)，或者在本地运行（`npm install`，然后 `npm run web`，打开
   <http://localhost:5173>）。
2. 第一次打开时会出现欢迎卡片，有三个选项：**花 1 分钟看看导览**、**载入群论示例**（离线生成，不需要密钥）或
   **从空白开始**。
3. 点工具栏右侧的状态标签 **配置 AI**，选择一个服务商（见下文）。没有密钥就选 **离线演示**：它内置一个很小的抽象代数
   知识库和一个由知识库生成的“模拟网页搜索”，遇到中文概念名会用中文回答。
4. 点 **添加概念**，输入一个名称（例如 *核*、*同态*、*第一同构定理*），从找到的来源中选一个定义。然后点概念上的
   **用 AI 检查** 标签，找出它的前置知识。

示例图谱会使用界面语言：中文界面下是 群论（群、子群、正规子群、同态、核、商群、第一同构定理），其中一个概念缺少
前置知识 同构，被阻塞，你可以马上试试 **安装**。

## 配置 AI 服务商

打开 **设置**（工具栏右侧的 AI 状态标签），先选连接方式：

- **直接从浏览器调用**（默认）：粘贴你的 API 密钥即可，不需要服务器。
- **通过本地 NodeStorm 服务器**：密钥保存在你电脑上的 `server/.env` 里（见[本地服务器](#本地服务器可选)）。

然后选择服务商和模型。模型列表直接从服务商的 API 读取，输入文字可以筛选。

| 服务商 | 默认模型 | 说明 |
|---|---|---|
| SiliconFlow 硅基流动（默认） | `deepseek-ai/DeepSeek-V3` | 读取扫描版 PDF 的视觉模型为 `Qwen/Qwen2.5-VL-72B-Instruct` |
| Anthropic Claude | `claude-opus-5` | 命名和找关系时可选用网页搜索 |
| DeepSeek 深度求索 | `deepseek-chat` | |
| Moonshot（Kimi） | `moonshot-v1-8k` | |
| 智谱（GLM） | `glm-4-flash` | |
| 阿里通义千问（DashScope） | `qwen-plus` | |
| Ollama（本地） | `qwen2.5:7b` | 不需要密钥，可离线；浏览器模式下请用 `OLLAMA_ORIGINS="*" ollama serve` 启动 |
| 兼容 OpenAI 的接口 | `gpt-4o-mini` | 其他任何兼容接口（OpenAI、vLLM、LM Studio 等），非对话模型会被隐藏 |
| 离线演示 | 内置 | 不需要密钥和网络，结果固定（测试就是用它跑的） |

默认模型只是起点，设置里会列出你的密钥实际能用的模型。

- **AI 回答** 设置决定 AI 用什么语言写。选“自动”时跟随你的概念名称的语言，也可以指定一种（English、中文……）或者
  自己输入。界面语言是另一个独立的设置。
- **视觉模型** 用于在“一起推导”里读取扫描版 PDF 页面。
- 遇到限流（HTTP 429）或服务商短暂故障时，会在超时之前自动重试最多两次。同时最多运行 3 个 AI 请求（可以调整），
  其余的在状态栏显示为“排队中”，可以在那里取消。
- 浏览器模式下，设置里会显示本次会话大约用了多少 token。

**你的密钥。** 浏览器模式下由页面直接调用服务商，密钥只会发给那个服务商。默认情况下密钥只保存在当前标签页，关闭即
忘记。勾选 **在这台设备上记住密钥** 后，它会保存在浏览器的 localStorage 里。请只在自己的设备上这样做，因为浏览器
扩展和使用同一浏览器配置的其他人都能读到它。**清除所有已保存的密钥** 会把它们删掉。建议单独建一个设了消费上限的
密钥。

## 定义从哪里来

按名称添加概念时，NodeStorm 会同时询问这些来源：

- **百科和维基**（设置 → **定义**）：**ProofWiki**（严谨的数学定义，其宏会转换为标准 LaTeX）、**维基百科和
  Wikidata**（使用你的回答语言，公式保留为 LaTeX）、中文名称还会查 **百度百科** 和 **萌娘百科**（日文名称也会查
  萌娘百科），以及你在设置里填写的 **Fandom** 或 **BWIKI** 维基。
- **网页搜索引擎**（设置 → **网页搜索**）：**Tavily**、**Serper**（Google 结果）、**Brave Search** 和
  **SearXNG**（你自己的实例）。每个引擎都要填自己的密钥（SearXNG 填地址），并有一个 **测试** 按钮。默认最多使用
  6 条结果。Brave 的 API 不接受网页直接调用，所以只能通过本地服务器使用。SearXNG 实例需要开启 JSON 输出，并允许
  来自本站的请求。在 https 的网站上，浏览器会拦截 localhost 以外的 http:// 地址，设置里会提醒你。

来源一找到就会显示，此时尚未评估：AI 调用可能要等很久，所以只有在弹窗里点 **用 AI 检查可靠性** 时 AI 才会核查
（核查期间可以继续选择，也可以停止）。在设置里打开 *找到来源后立即自动用 AI 评估* 可以让它立即进行；完全自动添加
概念的方式总会这样做。

需要时，AI 会**把这些来源互相对照打分**：**可靠**、**较可靠**、**存疑** 或 **不可用**，并说明原因，比如
网站的权威性、是否与其他来源一致、是不是论坛或广告、是不是在讲这个名称的另一种含义。它还会在每个来源的原文里标出
一段话。AI 被告知网页文字只是数据，不是指令；试图操纵它的网页会被评为不可用。

**“X”的来源** 弹窗按可靠程度列出这些来源；如果它们说的是不同的东西，会按含义分组。每个来源都显示网站名、原网页
链接，以及在来源原文中标出的段落。你可以选择：

- 某个来源里标出的段落；
- 来源里的任意其他文字：选中后点 **使用选中的文字**；
- **我自己的定义**。**编辑副本** 会先填入某个来源的原文：如果只是删减，它仍算那个来源的原话；如果改动了内容，就
  记为你自己写的。

保存的定义总是所选文字本身，附带来源网页的链接和 AI 的评分（检查器里显示“可靠（AI 对照了 3 个来源）”，点 **原因**
可以看理由）。AI“引用”的段落如果在来源中并不存在，会被丢弃。点 **稍后** 会让概念处于“需要定义”状态，点它的标签
可以重新打开弹窗。

- **没有配置 AI** 时仍会列出来源，只是不打分。**没有配置搜索引擎** 时只查百科，弹窗里会有前往“设置 → 网页搜索”的
  链接。
- **自动选择。** 默认由你在弹窗里选。如果在设置里取消勾选“添加概念时，先显示各个来源让我选择”，NodeStorm 会自动
  采用最可靠的段落；**全部安装** 也总是自动选择。只有在稳妥的情况下才会自动选：
  - 名称完全一致、被评为可靠的百科页面可以单独采用；
  - 网页需要“第二意见”：同一含义下，还有一个百科或另一个网站的页面被评为至少较可靠；
  - 同样可靠的来源说的是不同含义，或百科页面对应的是另一个名称时，不会自动采用。

  这些情况下会弹窗询问你（全部安装时，概念会留在“需要定义”状态）。
- **从…查找**（检查器里，来源旁边）可以从某个网站重新定义概念，或选 **搜索网页并比较…**，更改算一步撤销。弹窗里的
  **重新搜索** 会跳过搜索引擎 30 天的缓存重新搜索，因此会消耗搜索额度。
- 找到的来源会保存一天，重新加载页面后点概念的标签，可以直接看到已打分的来源，无需再次搜索。网页搜索结果缓存
  30 天。拒绝请求的网站或引擎会被跳过 10 分钟。
- ProofWiki 前面有 Cloudflare 的机器人检查，经常拒绝应用的请求，所以定义通常来自维基百科。

**哪里会出现 AI 自己写的文字。** 查找得来的定义绝不由 AI 撰写。AI 自己提出的概念（根据你的描述命名、**推导**、
**推荐关联**、**从文本提取**）以及讲解里的 **用摘要作为定义**，带的是 AI 写的文字；它们的来源会标为 “AI”，并注明
服务商和模型，一眼就能区分。**从…查找** 可以用某个来源的原话替换这类定义。

## 前置知识：用 AI 检查、安装、全部安装

- **用 AI 检查。** 有定义的概念会显示 **用 AI 检查** 标签（检查器里是 **用 AI 检查前置知识**）。AI 会列出它的
  直接前置知识：图谱里已有的会用虚线（前置知识连线）连起来，标签从需要它的一方来写（“使用”“推导出”“假设”）；缺少的会**阻塞**这个
  概念。
  *例子：* 先添加 *同态*，再添加 *第一同构定理*。定理会显示为被阻塞，缺少 *同构*；安装它之后，定理就就绪了。
- **安装**（检查器）会添加缺少的前置知识、连上线并查找它的定义。在默认的“先让我选择”模式下，单个安装只采用名称
  完全一致的百科页面，不做网页搜索，以节省搜索额度；否则概念会等你来选。
- **全部安装…** 按广度优先安装所有缺少的前置知识，再安装它们的前置知识，直到达到深度上限（默认 3）或新概念数量
  上限（默认 15），两者都可在设置里修改。进度显示在状态栏，在那里取消会停止整个过程。开始前会自动保存一个版本。
- **基础概念**（检查器）表示这个概念被视为已知：它不需要前置知识，缺少的前置知识会被移除，它永远不会被阻塞，也
  不会对它调用 AI 检查。被阻塞概念的缺失列表里也可以直接把它设为基础概念。
- **学习路径**（检查器）按学习顺序列出一个概念所依赖的一切，并标出还缺少的前置知识。**高亮** 会在画布上显示这条链。
- **循环依赖**（A 需要 B，B 又需要 A）通常说明 AI 答错了。AI 会读出每条连线当初被添加的理由，删掉错误的那条，
  Ctrl+Z 可以恢复。在设置 → **循环依赖** 里关掉后，只会显示警告。

## 构建图谱

- **添加概念。** 输入名称；或者选 **描述一下**，让 AI 为你描述的东西推荐规范的名称。新概念会出现在你正在看的位置
  附近的空处。
- **混合。** 选中两个概念后点 **混合**，AI 会**分别从两个方向**找出它们的关系。每条关系线两端都有箭头：B 端的
  箭头表示 A 对 B 做了什么，点击箭头即可查看。两个方向都没有关系时，这条线会用单独的颜色画出，标为“没有关系”。
- **推导** 根据选中的概念提出新概念及其关系，由你逐个接受。对话框里可以先 **创建沙盒**，让原图谱保持不变。
- **推荐关联**（检查器 → 关系）找出这个概念可以连接的概念：先是它的定义里提到的、图谱中已有的概念（不用 AI），然后
  是 AI 的建议。你勾选要添加的。
- **从文本提取**（**文件 → 从文本提取…**）读取粘贴的笔记、书中的段落或 `.txt`/`.md` 文件（最多 12,000 字符）。
  候选概念、关系和前置知识会先给你审阅再添加，图谱里已有的概念会被识别出来。
- **沙盒。** **创建沙盒**（图谱选择器旁边的分支图标）会复制当前图谱。在副本里推导、混合、安装，然后在沙盒横幅上
  选择 **合并回去** 或 **丢弃**。
- **一切都能手动修改。** 重命名概念（旧名称会保留为别名），编辑定义或关系文字，把关系的某一方向设为 **这个方向没有
  关系**，或者删除。**Ctrl/Cmd+Z** 撤销、**Ctrl/Cmd+Shift+Z** 重做，每个图谱分别记录。稍后才返回的 AI 结果不会
  单独成为一步撤销。
- 每种连线的颜色都可以在设置 → **关系颜色** 里调整，视图菜单里有图例。

## 视图与大图谱

- **整理** 把图谱分层排列，前置知识在上方。**查找概念**（Ctrl/Cmd+K）按名称、别名或笔记中的文字查找概念并居中显示。
- **聚焦**（在画布上按 **F**）只显示选中的概念以及与它相隔 1–3 条关系的概念，按 **Esc** 恢复全部。
- **视图**（眼睛图标）可以隐藏某类关系、关系标签或某类概念。**只看待办** 只留下被阻塞、不明确和失败的概念。这些选择
  会记在当前浏览器里。
- **暂时隐藏概念。** **H** 隐藏选中的概念，**Shift+H** 隐藏其余所有概念；也可以用检查器里的眼睛按钮，或
  **视图 → 隐藏所选 / 隐藏其余**。隐藏的概念会从画布、小地图、整理和 3D 视图中移除，但不会被删除、导出或分享，新开
  的标签页会显示全部。画布角落的“已隐藏 N 个 · **全部显示**”会列出它们。
- **多选**（缩放按钮旁的按钮）是为没有 Shift 键的触屏准备的：开启后，点按概念就会把它加入或移出选择，用于混合和
  推导。在触屏上长按卡片也会开启多选。用鼠标时，Shift 或 Ctrl 点击效果相同。
- **分层（2.5D）**（视图 → 布局）让概念站在一层层叠起来的平板上，每层对应一个依赖深度。**3D 视图…**（视图菜单）
  以 3D 方式展示这些层：拖动或单指旋转，滚轮或双指捏合缩放；旁边的层级列表不用画布也能使用。
- **物理**（磁铁按钮）让关系像弹簧一样拉扯、卡片互相推开，图谱会按连接关系自己排好。双击卡片可以固定它。最多支持
  400 个概念的图谱。
- 概念达到 150 个时只绘制屏幕上可见的部分，缩得很小时会省略关系标签。

## 学习工具

- **深入讲解**（检查器）：选择层次（*直观*、*严谨* 或 *举例*），还可以选一个恶搞旁白（*自然纪录片*、*体育解说*、
  *黑色侦探*、*中世纪学者*、*亢奋的电视购物*、*莎士比亚腔*）。旁白只改变讲述方式，数学内容保持正确。讲解会保存在
  概念上，旁边是你自己的 **我的笔记**。
- **测验**（**文件 → 测验…** 或检查器）：一次一个概念，先考前置知识，可以是自由回忆或选择题。自己评分：**会 /
  部分会 / 不会**。评分会成为概念的掌握度，以彩色圆点显示；掌握度会随时间减弱，所以下次测验会先问你不会的。
- **抽认卡（Anki）…**（**文件**）：生成定义、前置知识和关系卡片，可导入 Anki（公式会转换为 Anki 的 MathJax 格式）
  或导出为 CSV。拆解过的定理还会生成关于各个假设的卡片。
- **逐步讲解…**（**文件** 或检查器）：全屏、只读的演示，按学习顺序每页一个概念。
- **一起推导**（工具栏或 **文件**）：你自己推导一道题，AI 导师**只给提示**，绝不替你写步骤或答案。
  - **文档：** 导入 PDF、文本或 Markdown 文件。**习题集** 会被拆分成一道道题目供你挑选；**参考资料** 是导师引用的
    内容，形如 `[1] 笔记，第 4 页`，点击引用即可打开那一页。也可以选中一段文字，点 **用选中的文字作为题目**，或者
    直接输入题目。
  - **PDF 导入** 读取文字层，包括没有嵌入字体的中文、日文和韩文 PDF。扫描页面（包括黑白传真、JBIG2 或 JPEG 2000
    格式的扫描件）会以图片形式发给 **视觉模型**，公式会被读成 LaTeX。读不出来的页面可以手动粘贴文字。
  - **步骤：** **检查** 会把每一步标为*正确*、*有漏洞*、*错误* 或 *不清楚*。**提示** 每次追问都会更具体。
    **二号审稿人** 会写一份故作刻薄的审稿意见，但其中的问题应当是真实的。
  - **加入图谱：** 题目会成为一个概念，连到它用到的概念上，并记下来源页码，你的步骤会存进它的笔记。文档和推导按
    项目保存在当前浏览器里；**复制为 Markdown** 可以导出推导过程。

## 数学与形式科学

- **公式** 用 LaTeX 书写（`$…$`、`\(…\)`、`$$…$$`、`\[…\]`），在卡片、检查器、讲解、测验和提议中都会用 KaTeX
  排版。“$5 and $10” 这样的价格会保持为普通文字。
- **公式转 LaTeX**（检查器里定义的 **编辑** 旁边）：如果定义里的公式是用 Unicode 符号写的（“φ(ab) = φ(a)φ(b)”、
  “x² ≤ y”），AI 只把这些公式改写为 LaTeX。改动了其他文字的答案会被拒绝；来源保持不变，撤销一次即可恢复原文。
- **概念类型：** *定义*、*定理*、*引理*、*命题*、*推论*、*公理*、*猜想*、*例子*、*记号* 或 *其他*，在卡片上以
  小标签显示。AI 只在类型未设置时给出建议，不会覆盖你自己的选择。
- **定理解剖**（检查器里的 **拆解**）：每个假设为什么必要、去掉它时的反例、结论、证明思路、例子和反例。
- **在 Mathlib 中查找**（检查器）：AI 推荐 Lean 4 声明，每个都用 Loogle 在 Mathlib 中核对，只列出真实存在的。
- **查找论文**（检查器）：从 [OpenAlex](https://openalex.org) 找关于这个概念的真实论文，不用 AI。每个网络每天大约
  有 100 次免费查询。
- **导入 LaTeX（.tex）…**（**文件**）：论文中的每个定义、定理、引理等都会成为对应类型的概念，并按 `\ref` 引用
  连线。添加前先审阅，全程不用 AI。
- **LaTeX 文档（.tex）**（**文件**）：一篇可编译的 `amsart` 文章，每个概念一个定理环境，按学习顺序排列。
  **记号表…** 列出图谱引入的符号。

## 恶搞模式

- **荒诞链**（混合旁边的面具按钮，或 **文件 → 荒诞链…**）：事实是真的，推理是荒唐的。给出两个概念（来自图谱或
  直接输入），选择风格（*面无表情*、*阴谋论*、*史诗*、*官僚公文*、*学术过度*）和长度（3 到 7 环）。每一环都应当是
  真实、可查证的事实，只有旁白、标题和寓意是搞笑的。
  - **途经：** 最多加 6 个你自己的中途站，可以是图谱里的概念，也可以是你自己写了简短说明的概念。链条会按顺序经过
    它们，顺序可以调整。
  - **再来一条** 换一条路线，**复制为文本** 复制下来，**添加到沙盒** 会把链条放进一个新沙盒，只有合并回去时才会
    改动你的图谱。**给我惊喜** 随机挑两端。
  - **猜链条** 是个游戏：根据每一环的关系猜出两端之间隐藏的概念，有线索，并按每对端点记录最高分。
- 这些事实来自 AI：引用之前请先核实。

## 项目、沙盒与版本

- **项目**（工具栏最左边的菜单）：多个互不相干的头脑风暴，每个都有自己的主图谱和沙盒。一切都会自动保存在当前浏览器里。
- **历史版本…**（**文件**）：恢复点。在大改动之前（全部安装、添加提取的概念、合并或丢弃沙盒、整理、恢复版本）以及
  编辑期间每 10 分钟会自动保存一个；也可以用 **文件 → 保存快照…** 手动保存。列表里可以 **对比**、**预览**、
  **恢复** 或 **恢复为新项目**。

## 导出与分享

**文件** 菜单里有：

- **JSON（当前项目）**，包括沙盒。**导入 JSON…** 会把文件添加为新项目；损坏或手工改过的文件会被修复，而不是拒绝。
- **Markdown 笔记**（使用界面语言，公式保留为 `$…$`）、**LaTeX 文档**、**Mermaid 图**、**PNG 图片** 和
  **抽认卡（Anki）…**。
- **分享链接…** 把当前图谱打包进一个链接。不需要账号或服务器：图谱被压缩进网址中 `#` 之后的部分，浏览器从不会把这
  部分发给服务器。对方以只读方式查看，可以 **保存副本**。你的笔记、讲解、测验进度和保存的查询结果不会包含在内。有些
  聊天软件会截断超过约 8,000 个字符的链接，大图谱请改发 JSON 导出文件。

## 离线使用与安装

这个网站可以作为应用安装：在 Chrome 或 Edge 中使用地址栏或菜单里的 **安装应用**；在 iPhone 和 iPad 上用 Safari
的 **分享 → 添加到主屏幕**。首次访问之后，没有网络也能打开。离线时会有横幅提示，AI 操作会立刻停止并给出说明；
**离线演示** 和本地的 Ollama 仍然可用。离线副本只包含应用自身的文件，对 AI 服务商、查询网站、搜索引擎和本地服务器的
请求总是走网络。部署了新版本时会出现 **有新版本可用** 的提示，在你点 **重新加载** 之前什么都不会变。

## 语言、手机与无障碍

- **设置 → 界面：** 主题可选 **自动**、**浅色** 或 **深色**；界面语言可选 English 或 中文（简体），默认跟随浏览器。
  AI 的回答语言是另一个设置。
- **手机：** 不常用的按钮收进 **更多工具** 菜单，检查器变成底部面板，**多选** 代替 Shift 点击，3D 视图支持手指手势。
- **键盘与读屏软件：** 所有功能都能用键盘操作。对话框会锁定焦点，关闭后把焦点还回去，提示信息会被朗读。端到端测试会在
  两种主题和中文界面下运行 axe（WCAG A/AA）检查。

## 隐私：什么会发到哪里

NodeStorm 没有账号，互联网上也没有 NodeStorm 服务器。你的项目、版本和文档都保存在你的浏览器里（localStorage 和
IndexedDB）。

| 内容 | 发送给 |
|---|---|
| 每个 AI 任务用到的概念名称、定义和相关概念（最多 500 个）；需要打分的来源文字；一起推导中的题目、你的步骤和文档片段；扫描页面的图片 | 你选择的 AI 服务商（直接发送，或经你的本地服务器） |
| 概念名称 | 你启用的百科和维基（ProofWiki、维基百科/Wikidata、中文名称的百度百科和萌娘百科、你的 Fandom/BWIKI 维基） |
| 形如 `"<名称>" definition` 或 `<名称> 定义` 的搜索词 | 只发给你在“设置 → 网页搜索”里勾选的搜索引擎 |
| AI 推荐的 Lean 名称 | Loogle，在你点“在 Mathlib 中查找”时 |
| 概念名称（有时加上几个前置知识的名称） | OpenAlex，在你点“查找论文”时 |
| 分享的图谱 | 谁也不发：它在链接的 `#` 部分里，不会发给任何服务器 |

- 查询和搜索都不发送 cookie。百度百科的结果在一个沙盒框架里读取，这个框架访问不到页面、你的密钥或存储。
- AI 服务商和搜索引擎的 **API 密钥** 只保存在当前标签页（sessionStorage），除非你勾选 **在这台设备上记住密钥**，
  那样会存进 localStorage。密钥绝不会出现在导出文件、分享链接或历史版本里。浏览器模式下，每个密钥只发给它自己的服务。
- 使用本地服务器时，密钥可以只放在 `server/.env` 里，完全不经过浏览器。

## 本地服务器（可选）

以下情况需要本地服务器：

- 不想把密钥放在浏览器里（改放在 `server/.env`）；
- 要用 **Brave Search**（它的 API 不接受网页直接调用）；
- 要连接一个不允许本站跨域请求的 SearXNG 实例。

```bash
cp server/.env.example server/.env   # 填入你的密钥
npm run dev                          # 服务器在 :8787，界面在 :5173
npm run dev:mock                     # 同上，但使用离线演示 AI（不需要密钥）
```

然后在设置里选择 **通过本地 NodeStorm 服务器**。

- AI 服务商通过 `<PROVIDER>_API_KEY`、`<PROVIDER>_BASE_URL` 和 `<PROVIDER>_MODEL` 配置（例如
  `SILICONFLOW_API_KEY`、`DEEPSEEK_MODEL`），另有 `AI_PROVIDER`（默认服务商）和 `ANTHROPIC_WEB_SEARCH=1`。浏览器
  可以选择服务商和模型，但永远不能选择密钥。
- 网页搜索优先使用设置里填写的密钥，否则使用 `server/.env` 中的 `TAVILY_API_KEY`、`SERPER_API_KEY`、
  `BRAVE_API_KEY` 和 `SEARXNG_URL`。
- **它没有登录，而且会花你的密钥**，所以只监听本机（127.0.0.1，端口为 `PORT`，默认 8787）。只有在你自己加了身份
  验证的前提下，才设置 `HOST`（例如 `HOST=0.0.0.0`）。
- **防 DNS 重绑定：** 它只响应发往 `localhost`、`127.0.0.1`、`[::1]` 或 `HOST` 的请求，并拒绝其他网站页面发来的
  请求，所以恶意网页无法花你的密钥。如果你用别的名称访问它，把这个名称写进 `NODESTORM_ALLOWED_HOSTS`（多个用逗号
  分隔）。
